# Portrait care with existing components

John requested eight consistent buttons, action speech bubbles, matching props, and scenery switching. The assignment still permits only the three supplied scripts.

Use Animator states and existing Button events. A second instance of PetButtons supplies the speech bubble timer. An independent background Animator consumes a Next trigger and preserves care feedback while changing scenery.

A new care controller would centralize this behavior but would add an unauthorized script. Scene unloading would need separate audio and status lifetime decisions. The component configuration keeps script files unchanged; new behaviors must be verified through real button presses.
